# OD.Converter 1.3.0 — Audio/video workflows, optional AI modules and a refreshed console

OD.Converter 1.3.0 expands the Windows audio converter into an audio/video processing toolkit. Extract video soundtracks, separate vocals from background audio, generate transcripts and subtitles, or combine separation and transcription. This release also introduces a redesigned interactive console and a complete offline English/French user guide.

## Download and start

Download **odconv.exe** from the assets below and place it in a folder of your choice on **Windows x64**. The self-contained executable includes .NET 10 and FFmpeg/FFprobe 8.1.2. Basic conversion and soundtrack extraction work offline, without installing .NET, Python or either optional AI module.

Double-click the EXE to open the main menu, or run it from PowerShell:

```powershell
.\odconv.exe
.\odconv.exe --version
```

Keep the executable in a writable folder to let the help menu extract its HTML guide beside it. AI engines and models are downloaded separately only when you explicitly request module installation.

## New audio and video workflows

- **Soundtrack extraction:** process an audio source or extract the selected audio stream from a video with the new `process` command and shared interactive workflow.
- **Complete audio-track inspection:** `probe` now reports all audio streams, with absolute stream indexes, audio ordinals, languages, titles and audio characteristics. Select the required track explicitly in the menu or with `--audio-track`.
- **Vocal/background separation:** the optional private Demucs CPU module exports isolated vocals and background/instrumental audio, with an optional original soundtrack export.
- **Transcription and subtitles:** the optional Whisper CPU module creates a global UTF-8 TXT transcript and SRT subtitles in the selected or detected source language.
- **Combined processing:** separate the source first, then transcribe the aligned vocal track in one request.
- **Flexible exports:** choose compatible outputs, audio encoding, output directory and filename prefix. Names distinguish original audio, vocals, background, transcript and subtitles.

```powershell
.\odconv.exe probe "clip.mp4"
.\odconv.exe process "clip.mp4" --action extract --audio-track 2 --to wav --bit-depth 24
.\odconv.exe process "song.wav" --action separate --exports original,vocals,background
.\odconv.exe process "interview.wav" --action transcribe --language en
.\odconv.exe process "clip.mp4" --action separate-transcribe --language fr --output-dir "D:\Exports" --prefix clip-fr
```

The stream index is the **absolute FFprobe index**, which can differ from a track's ordinal among audio streams. Videos without audio are rejected clearly before processing. Transcription keeps the source language; translation and speaker identification/diarization are not included.

## Timing, output integrity and cancellation

- Audio preparation preserves presentation offsets, delayed tracks, silence and timestamp gaps relative to the source timeline.
- PCM lengths are measured and normalized to the target duration. WAV/PCM remains the reference for editing and alignment; compressed exports may introduce encoder delay.
- Unknown or inconsistent source timelines are rejected explicitly instead of silently guessed. Timestamp-free PCM WAV uses sample zero as its announced origin.
- All requested destinations are checked before expensive processing. Sources cannot be overwritten.
- Process exports are written to temporary files and finalized individually after successful export. If a later step fails or is cancelled, completed exports are retained and missing results are reported.
- Ctrl+C cancels processing and stops child processes. Temporary work is cleaned up, with a warning if cleanup fails.

## Independent optional CPU modules

The **Optional modules** menu and `modules` command provide **List, Status, Verify, Install, Repair and Uninstall** operations. States distinguish **Not installed**, **Installing**, **Ready** and **Needs repair**.

- **Separation:** Demucs 4.0.1, private CPython 3.11.9, PyTorch/torchaudio 2.6.0 CPU and the `htdemucs` model.
- **Transcription:** native whisper.cpp 1.8.2, multilingual `large-v3-turbo-q5_0` and Silero VAD for speech detection.
- Private storage under `%LOCALAPPDATA%\OD.Converter\modules`; no global PATH changes, no implicit Python environment and no dependency on another application's installation.
- Pinned downloads with size/SHA-256 verification, private runtime libraries and retained third-party license notices.
- Installation locking, isolated generations, functional checks before activation, cancellation and targeted repair/uninstall.
- Conversion, extraction and module inspection do not implicitly install or download an AI engine. A GPU is not required.

```powershell
.\odconv.exe modules list
.\odconv.exe modules install separation
.\odconv.exe modules install transcription
.\odconv.exe modules verify transcription
.\odconv.exe modules repair transcription
.\odconv.exe modules uninstall separation
```

Installation and repair require network access and sufficient disk space. CPU inference can take substantial time and memory. Uninstall removes only the selected module and its cache; source media, exports and the other module are retained.

## Refreshed interactive console

- Shared ASCII banner with the application name and version.
- Consistent colors, high-contrast selections and descriptions of the main menu choices.
- Numbered workflow stages for source selection, treatment/exports, destination and final review.
- Rounded tables and panels for source information, settings and module status.
- More readable module-state labels, processing results, warnings and command-help sections.
- A conversion activity indicator and retained output history when returning from a workflow.
- A **Buy me a coffee** section for voluntary support, using Olivier Dahan / KNHSynths' existing page shared with HarmoTools. Opening the support page is an explicit menu action.

Classic audio conversion, batch/folder conversion, existing encoding options and direct-file launch remain available. Passing a file directly still opens classic conversion. `probe --json` remains raw FFprobe JSON for scripts.

## Complete offline English/French help

A single self-contained **HTML/CSS user guide** covers installation, interactive menus, module management, commands, formats, output naming, timing, limitations and troubleshooting. It includes an internal contents menu, light/dark themes, responsive layouts and print styles, with no JavaScript or required external resources.

The guide is embedded in the EXE. Select **User guide / Guide utilisateur**, or run:

```powershell
.\odconv.exe guide
.\odconv.exe guide --extract
```

The guide is extracted as `odconv-user-guide.html` beside the running EXE and opened in the default browser. Older content is refreshed atomically; an identical copy is left untouched. `--extract` writes the document without opening the browser. If browser launch fails, the HTML remains available for manual opening. A standalone copy is also attached to this release as **user-guide.html**.

## Validation and known limitations

- **179 automated tests passed**, with no failures or skipped tests in the final application test run.
- Real FFmpeg conversion/extraction and raw-JSON regression checks passed with the published executable.
- The standalone executable's embedded guide was extracted and verified against its source by SHA-256; browser invocation and menu error recovery were checked.
- Browser checks covered desktop/mobile layouts, light/dark themes and internal links.
- Earlier audio/video validation includes measured PCM alignment over two hours, multiple video containers and real CPU Demucs/Whisper runs. The episode 17 transcript and separation listening checks were accepted by the user.
- **Clean Windows validation remains deferred.** Local isolation tests do not establish successful execution on a fresh Windows installation.
- Additional representative interviews, ambient sources, multiple-speaker recordings and language changes remain deferred. Automatic language detection has an observed omission on a bilingual fixture; specify a known source language when possible and review transcripts/subtitles.
- AI separation can leave artifacts or remove wanted sounds. Speech detection can miss difficult or quiet voices. Text, phrase boundaries and perceptual separation quality require human review.

Reproducible validation tools, a transferable clean-Windows validation kit, specifications and detailed implementation/validation records are included in the repository. These deferred checks are documented rather than counted as successful tests.
