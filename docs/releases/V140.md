# OD.Converter 1.4.0 for Windows x64

OD.Converter now includes a Windows 11 desktop app alongside the existing command-line interface.

- **odconv-gui.exe** provides audio conversion, audio/video processing, media inspection and optional module management in a dark WPF interface.
- **odconv.exe** provides the terminal commands, scripts and interactive console menus.
- **SHA256SUMS.txt** contains the checksums for both executables.

Both downloads are standalone and include FFmpeg, FFprobe and the offline English/French user guide. Conversion, inspection and soundtrack extraction work offline. Optional Demucs and Whisper CPU modules are shared by both apps and installed on request.
