# OD.Converter for Windows x64

- Download **odconv.exe** for the terminal, scripts and the interactive console menus.
- Download **odconv-gui.exe** for the desktop interface on Windows 11 x64.
- Verify the file you downloaded against **SHA256SUMS.txt**.

Each executable is self-contained and includes FFmpeg, FFprobe and the offline English/French guide. Conversion, inspection and soundtrack extraction work offline. Separation and transcription use optional CPU modules. Install them explicitly from either application to use them in both.
