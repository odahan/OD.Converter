ENGLISH / USER GUIDE

From a media file to the output you need.

Convert audio, extract a video soundtrack, isolate vocals or generate a transcript and subtitles. Use the guided menus or automate the same tasks from the command line.

Convert & extract

Built-in FFmpeg. Works offline without optional modules.

Separate & transcribe

Optional Demucs and Whisper CPU engines, installed explicitly.

01 / Getting started

  1. Place odconv.exe in a folder of your choice on Windows x64. No .NET or global Python installation is needed for the self-contained release.
  2. Double-click the EXE, or run odconv in a terminal from its folder. In PowerShell, use .\odconv.exe if it is not on PATH.
  3. Select Process audio / video for soundtrack extraction, separation or transcription, or Convert audio (classic) for guided audio conversion.

Examples below use odconv. Quote paths that contain spaces. Dragging an audio file onto the EXE, or running odconv "song.wav", opens classic conversion directly.

Keep this guide nearby. The menu entry User guide / Guide utilisateur extracts odconv-user-guide.html beside the running EXE and opens your default browser. The file is refreshed when the embedded content changes. The EXE folder must be writable. The guide itself requires no network, JavaScript, external fonts or other files.

02 / Interactive menus

The interface is in English. Use ↑ / ↓ to move, Enter to select, and Space to toggle export checkboxes. Defaults appear in prompts. Choose Back to return, or leave the source prompt blank. Ctrl + C cancels the session.

Process audio / video

  1. Source & audio track. Enter or drop a media path. Review its audio tracks. For a file with several tracks, select the required stream using its language, title and index. A video without audio cannot be processed.
  2. Treatment & exports. Select one of the available actions below. Actions whose modules are unavailable are shown in grey outside the selectable list. Choose the files to create.
  3. Settings & destination. For transcription, choose the source language (en, fr, or auto). For audio exports, choose encoding settings. Set the destination folder and filename prefix.
  4. Review & start. Review all output paths. Existing destinations require explicit overwrite confirmation. Confirm processing, then read the results or any missing-output messages.
Action Result / default exports Modules
Convert / extract audio Complete soundtrack: original None
Separate voice and background vocals,background; original also available separation
Generate transcript and subtitles transcript,subtitles transcription
Separate and transcribe vocals,background,transcript,subtitles; original also available. Transcribes isolated vocals. Both

Convert audio (classic)

Select a source, target format, bitrate or quality, mono setting, sample rate and output filename. Review the summary and start. You can convert another file afterward. For explicit track selection in a video, use Process audio / video.

03 / Optional modules

Open Optional modules, choose separation (Demucs) or transcription (Whisper), then choose an operation. Install, Repair and Uninstall require confirmation in the menu. CLI commands below execute the requested operation directly.

State / operation Meaning
Not installed Install the module before using its actions.
Installing A module operation already owns the installation lock; wait for it to finish.
Ready Integrity and offline functional checks passed.
Needs repair The module is damaged, incomplete or incompatible. Choose Repair.
Verify Check the installed module offline.
Install / Repair Download the pinned engine, runtime dependencies and model; verify before activation.
Uninstall Remove only the selected module and its cache. Sources, exports and the other module are retained.

Modules live under %LOCALAPPDATA%\OD.Converter\modules. Installation shows the location, version, CPU profile and download size first. Network access and sufficient disk space are required for Install and Repair; downloads can be large. Standard installation needs no administrator rights and does not change the global PATH. CPU processing can take substantial time and memory. A GPU is not required.

odconv modules list
odconv modules install separation
odconv modules install transcription
odconv modules status transcription
odconv modules verify separation
odconv modules repair transcription
odconv modules uninstall separation

04 / Command reference

CLI commands are noninteractive. Use --overwrite always only when replacement is intended. Each command accepts --help.

odconv --help
odconv --version
odconv formats
odconv probe "clip.mp4"
odconv probe "clip.mp4" --json
odconv guide
odconv guide --extract

probe (alias info) lists metadata and absolute audio stream indexes. --json returns raw FFprobe JSON for scripts. guide --extract writes the HTML next to the EXE without opening the browser.

Convert one file or a batch

odconv convert "song.wav" --to mp3 --bitrate 320k -o "song.mp3"
odconv convert "song.flac" --to ogg --quality 6
odconv convert "song.wav" --to wav --bit-depth 24 --mono --sample-rate 48000 -o "mono.wav"
odconv convert "first.wav" "second.wav" --to mp3 --output-dir "D:\Exports"
odconv convert . --to flac --recursive --pattern "*.wav" --output-dir "D:\Exports"
odconv convert "song.wav" --to opus --bitrate 128k --dry-run

-o / --output is for a single input. --output-dir sets the output root for a batch; --recursive includes subdirectories and --pattern filters directory inputs. --dry-run prints the FFmpeg invocation without converting.

Process an audio or video source

odconv process "clip.mp4" --action extract --audio-track 2 --to wav --bit-depth 24
odconv process "song.wav" --action separate --exports original,vocals,background
odconv process "interview.wav" --action transcribe --language en
odconv process "clip.mp4" --action separate-transcribe --language fr --output-dir "D:\Exports" --prefix clip-fr
Process option Usage / default
--action Required: extract, separate, transcribe or separate-transcribe.
--audio-track Absolute stream index from probe; defaults to the first audio track, announced at runtime.
--exports Comma-separated compatible names: original,vocals,background,transcript,subtitles. Defaults follow the action table.
--output-dir / --prefix Default: source directory / source filename without extension.
--language Source language: auto (default) or lowercase two-letter code. No translation.
--to Audio export format; defaults to WAV. Encoding options below also apply to audio exports.
--overwrite never (default) or always.
--ffmpeg Optional custom FFmpeg path, also available for convert and probe.

process accepts one source at a time. -o, --dry-run, recursive and batch options belong to convert.

05 / Formats & encoding

Supported output formats: WAV, AIFF, FLAC, WavPack (wv), ALAC, MP3, Ogg Vorbis, Opus, AAC, M4A/AAC and WMA. ALAC uses the .m4a extension. Input support depends on the bundled FFmpeg build. Video sources produce audio exports; the program does not export edited video.

Setting Values / guidance
--bitrate / -b Lossy bitrate, e.g. 128k, 192k, 320k. Defaults: MP3 320k, Opus 128k, AAC/M4A/WMA 192k.
--quality / -q MP3 VBR 0–9 (0 best); Ogg 0–10 (10 best, default 6).
--sample-rate 22050, 44100, 48000 or 96000 Hz; source rate retained when omitted.
--channels / --mono 1, 2 or 6 channels; --mono forces one channel and takes precedence. Source channel count retained when omitted.
--bit-depth WAV/AIFF: 16, 24 or 32 bits; default 16.
--compression FLAC: 0–8, default 5. Changes size and encoding effort, not audio fidelity.

For editing and timing checks, prefer WAV at an appropriate bit depth. Lossy formats reduce file size and can add encoder delay. Converting a lossy source to a lossless format cannot restore discarded detail.

06 / Files, timing & quality

Process exports use <prefix>-original.wav, -vocals.wav, -background.wav, -transcript.txt and -subtitles.srt. The audio extension follows the chosen format. Use different prefixes or directories for different sources with the same name.

Sources are protected from replacement. Process outputs are finalized individually after successful export; if a later step fails, already completed files are retained and missing files are reported. Cancellation cleans intermediate work where possible and reports cleanup failures.

Extraction and AI preparation preserve the source presentation timeline, including delayed tracks and silence; PCM lengths are measured. Unknown or inconsistent source timelines are rejected instead of silently guessed. Timestamp-free PCM WAV uses sample zero as its origin. Compressed exports may add encoder delay; use PCM as the editing reference.

Review AI output. Separation may leave artifacts or remove wanted sound. Transcripts and phrase boundaries require review. TXT/SRT are UTF-8 and global, without speaker identification or translation. Automatic language detection may omit a language in multilingual recordings; choose a known source language when possible. Clean Windows and additional representative media checks remain deferred; existing validation does not guarantee every source.

07 / Troubleshooting & exit codes

A treatment is unavailable

Open Optional modules, inspect its state and Install or Repair the required module. Extraction and classic conversion do not require either AI module. No module is downloaded implicitly.

File not found, no audio, or invalid track

Check the quoted path and run probe. Use the absolute stream index, which can differ from the audio ordinal. A silent video has no soundtrack to process.

The output exists or cannot be written

Choose another destination/prefix, or explicitly allow overwriting. Check folder permissions, free disk space and whether another program has the destination open. The source cannot be used as an output.

The guide does not open

Put the EXE in a writable folder and retry. Run odconv guide --extract, then open odconv-user-guide.html beside the EXE manually. Check your default browser association. The guide is also available as docs/user-guide.html in the source tree.

Processing fails or takes a long time

Read the last error and the list of completed outputs. Verify the modules, check memory and disk space, or try a shorter source. CPU AI processing may be slow. For timeline errors, inspect the source metadata; the program does not silently invent timing. Press Ctrl+C to cancel.

Exit codes: 0 success/help; 1 arguments, source or selection error; 2 required tool/module unavailable or module verification not ready; 3 processing or operational failure (including guide extraction/opening); 130 cancelled. Probe retains code 1 for analysis errors.

04 / Référence des commandes

Les commandes CLI ne posent pas de question. Utilisez --overwrite always lorsque le remplacement est souhaité. Chaque commande accepte --help.

odconv --help
odconv --version
odconv formats
odconv probe "clip.mp4"
odconv probe "clip.mp4" --json
odconv guide
odconv guide --extract

probe (alias info) affiche les métadonnées et les index absolus des pistes audio. --json renvoie le JSON FFprobe brut pour les scripts. guide --extract écrit le HTML à côté de l’EXE sans ouvrir le navigateur.

Convertir un fichier ou un lot

odconv convert "musique.wav" --to mp3 --bitrate 320k -o "musique.mp3"
odconv convert "musique.flac" --to ogg --quality 6
odconv convert "musique.wav" --to wav --bit-depth 24 --mono --sample-rate 48000 -o "mono.wav"
odconv convert "premier.wav" "second.wav" --to mp3 --output-dir "D:\Exports"
odconv convert . --to flac --recursive --pattern "*.wav" --output-dir "D:\Exports"
odconv convert "musique.wav" --to opus --bitrate 128k --dry-run

-o / --output désigne la sortie d’une source unique. --output-dir fixe la racine de sortie d’un lot ; --recursive inclut les sous-dossiers et --pattern filtre les fichiers d’un dossier. --dry-run affiche l’appel FFmpeg sans convertir.

Traiter une source audio ou vidéo

odconv process "clip.mp4" --action extract --audio-track 2 --to wav --bit-depth 24
odconv process "musique.wav" --action separate --exports original,vocals,background
odconv process "entretien.wav" --action transcribe --language fr
odconv process "clip.mp4" --action separate-transcribe --language en --output-dir "D:\Exports" --prefix clip-en
Option de process Utilisation / valeur par défaut
--action Obligatoire : extract, separate, transcribe ou separate-transcribe.
--audio-track Index absolu fourni par probe ; première piste audio par défaut, annoncée à l’exécution.
--exports Noms compatibles séparés par des virgules : original,vocals,background,transcript,subtitles. Valeurs par défaut selon le tableau des actions.
--output-dir / --prefix Par défaut : dossier source / nom de la source sans extension.
--language Langue source : auto par défaut ou code de deux lettres minuscules. Pas de traduction.
--to Format des exports audio ; WAV par défaut. Les options d’encodage ci-dessous s’appliquent aux sorties audio.
--overwrite never par défaut, ou always.
--ffmpeg Chemin FFmpeg personnalisé facultatif, également proposé par convert et probe.

process accepte une seule source à la fois. -o, --dry-run, les lots et les options récursives appartiennent à convert.

05 / Formats et encodage

Formats de sortie : WAV, AIFF, FLAC, WavPack (wv), ALAC, MP3, Ogg Vorbis, Opus, AAC, M4A/AAC et WMA. ALAC utilise l’extension .m4a. Les formats d’entrée dépendent du FFmpeg embarqué. Une source vidéo produit des exports audio ; le programme n’exporte pas de vidéo montée.

Réglage Valeurs / conseils
--bitrate / -b Débit avec perte, par exemple 128k, 192k ou 320k. Défauts : MP3 320k, Opus 128k, AAC/M4A/WMA 192k.
--quality / -q MP3 VBR de 0 à 9 (0 : meilleure qualité) ; Ogg de 0 à 10 (10 : meilleure qualité, défaut 6).
--sample-rate 22050, 44100, 48000 ou 96000 Hz ; fréquence source conservée si omis.
--channels / --mono 1, 2 ou 6 canaux ; --mono impose un canal et reste prioritaire. Nombre de canaux source conservé si omis.
--bit-depth WAV/AIFF : 16, 24 ou 32 bits ; défaut 16.
--compression FLAC : 0 à 8, défaut 5. Modifie la taille et l’effort d’encodage, sans altérer la fidélité du son.

Pour le montage et les contrôles temporels, préférez WAV avec une profondeur adaptée. Les formats avec perte réduisent la taille et peuvent ajouter un délai d’encodage. Convertir une source avec perte vers un format sans perte ne restaure pas les détails supprimés.

06 / Fichiers, chronologie et qualité

Les sorties de process sont nommées <préfixe>-original.wav, -vocals.wav, -background.wav, -transcript.txt et -subtitles.srt. L’extension audio dépend du format choisi. Pour deux sources portant le même nom, utilisez des préfixes ou dossiers différents.

Les sources sont protégées contre le remplacement. Les exports de process sont finalisés individuellement après succès ; en cas d’échec tardif, les fichiers terminés restent disponibles et les fichiers manquants sont signalés. L’annulation nettoie les intermédiaires lorsque cela est possible et signale les échecs de nettoyage.

L’extraction et la préparation IA conservent la chronologie de présentation, y compris les pistes retardées et les silences ; les longueurs PCM sont mesurées. Une chronologie inconnue ou incohérente est refusée au lieu d’être devinée. Pour un WAV PCM sans horodatage, l’échantillon zéro définit l’origine. Les exports compressés peuvent introduire un délai d’encodage ; le PCM reste la référence de montage.

Relisez et écoutez les résultats IA. La séparation peut laisser des artefacts ou retirer des sons utiles. La transcription et les limites des phrases demandent une relecture. TXT/SRT sont globaux, en UTF-8, sans identification des locuteurs ni traduction. La détection automatique peut omettre une langue dans un enregistrement multilingue ; choisissez la langue source connue si possible. Les contrôles Windows vierge et d’autres médias représentatifs restent reportés ; les validations existantes ne garantissent pas toutes les sources.

07 / Dépannage et codes de sortie

Une action n’est pas disponible

Ouvrez Optional modules, consultez l’état et installez ou réparez le module requis. Extraction et conversion classique ne nécessitent aucun module IA. Aucun module n’est téléchargé implicitement.

Fichier introuvable, absence de son ou mauvaise piste

Vérifiez le chemin entre guillemets et utilisez probe. Choisissez l’index absolu du flux, qui peut différer de son rang parmi les pistes audio. Une vidéo muette ne contient aucune bande sonore à traiter.

La sortie existe ou n’est pas accessible en écriture

Changez de dossier ou de préfixe, ou autorisez explicitement le remplacement. Vérifiez les permissions, l’espace disque et l’ouverture éventuelle du fichier dans un autre logiciel. La source ne peut pas servir de sortie.

Le guide ne s’ouvre pas

Placez l’EXE dans un dossier accessible en écriture, puis réessayez. Lancez odconv guide --extract et ouvrez manuellement odconv-user-guide.html à côté de l’EXE. Vérifiez l’association du navigateur par défaut. Le guide figure aussi dans les sources : docs/user-guide.html.

Le traitement échoue ou semble très lent

Lisez la dernière erreur et la liste des exports terminés. Vérifiez les modules, la mémoire et l’espace disque, ou essayez une source plus courte. Le traitement IA sur CPU peut être long. En cas d’erreur temporelle, inspectez les métadonnées ; le programme n’invente pas la chronologie. Ctrl+C permet d’annuler.

Codes de sortie : 0 succès/aide ; 1 erreur d’arguments, de source ou de sélection ; 2 outil/module requis indisponible ou vérification d’un module non prêt ; 3 échec de traitement ou d’opération (dont extraction/ouverture du guide) ; 130 annulation. Probe conserve le code 1 pour les erreurs d’analyse.
